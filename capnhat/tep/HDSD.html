KTool 1.23.0 – Hướng dẫn sử dụng

Công cụ VBA hỗ trợ biên tập bản đồ địa chính trên MicroStation V8i (SELECTseries 1–10, 32-bit) và MicroStation CONNECT Edition (64-bit): chuẩn hóa dữ liệu, kiểm tra và sửa lỗi topo, tạo vùng thửa, gán và quản lý thuộc tính, vẽ nhãn thửa, vẽ nhãn quy chủ, kiểm tra thuộc tính; tạo khung bản đồ theo TT 26/2024, nhập số liệu đo và nối điểm, lập sơ đồ hình thể và hồ sơ thửa đất (phiếu kết quả đo đạc, trích lục, bản mô tả ranh giới, trang in GCN), xuất Shapefile, chuyển đổi font TCVN3/VNI ↔ Unicode.

2. Cài đặt

2.1 Cài bằng file KTool_Setup_v1.23.0_PhatHanh.exe (khuyên dùng)

  1. Đóng MicroStation, giải nén gói cài, chạy KTool_Setup_v…_PhatHanh.exe (để KTool.mvba cùng thư mục) (cần quyền Administrator).
  2. Chọn thư mục cài (mặc định C:\KTool). Nên dùng đường dẫn không dấu, không khoảng trắng.
  3. Bộ cài sẽ:
  4. chép mã nguồn, file cấu hình mẫu, hướng dẫn vào thư mục cài;
  5. tìm mọi bản MicroStation trên mọi ổ đĩa (V8i / V8 XM / PowerDraft / Bentley Map – 32-bit; CONNECT Edition và các sản phẩm nền CONNECT – 64-bit; cài ở C:\Program Files\Bentley, D:\Program Files (x86)\Bentley, D:\Bentley…) và ghi file KTool.cfg vào ...\MicroStation\config\appl (V8i) hoặc C:\ProgramData\Bentley\<sản phẩm>\Configuration\Organization (CONNECT) để tự nạp công cụ mỗi khi mở MicroStation;
  6. kiểm tra và sửa môi trường VBA của MicroStation (mục 2.4), kết quả ghi trong KiemTraVBA.txt;
  7. tạo shortcut trong Start Menu: Cài vào MicroStation, Sửa lỗi VBA MicroStation, Hướng dẫn sử dụng, Gỡ cài đặt.
  8. Ở trang cuối, để nguyên ô "Khởi động MicroStation và nạp KTool ngay" rồi bấm Finish:
  9. nếu MicroStation chưa mở, bộ cài tự khởi động MicroStation (máy có nhiều bản thì hỏi chọn bản nào); chọn (hoặc tạo) một file DGN bất kỳ;
  10. ngay khi file DGN mở, công cụ tự tạo KTool.mvba, nạp toàn bộ module, tạo form, lưu project và hiện thanh công cụ (chờ tối đa 10 phút);
  11. nếu MicroStation đang mở sẵn một file DGN, công cụ được nạp ngay;
  12. nếu sau 45 giây macro cài đặt không chạy (VBA của MicroStation hỏng), bộ cài báo lỗi và đề nghị chạy Sửa lỗi VBA MicroStation.
  13. Nếu không tìm thấy hoặc không kết nối được với MicroStation, lệnh cài đã được chép sẵn vào clipboard: trong MicroStation mở Utilities > Key-in, dán (Ctrl+V) rồi Enter: @C:\KTool\CaiDat_KeyIn.txt
  14. Từ lần sau, thanh công cụ tự mở mỗi khi khởi động MicroStation (project được nạp tự động nhờ file KTool.cfg, thủ tục OnProjectLoad mở thanh công cụ). Khi mở file DGN khác, thanh công cụ vẫn giữ hoặc tự mở lại. Nếu bạn bấm × đóng thanh công cụ, nó sẽ không tự bật lại trong phiên đó; mở lại bằng key-in vba run [KTool]modMain.MoCongCu. Bật / tắt chế độ tự mở: menu Hệ thống > Tự mở khi khởi động MicroStation.

Cập nhật phiên bản mới: chạy bộ cài mới rồi làm lại bước 4 – project được tạo lại, file cấu hình KTool_CauHinh.ini ở các thư mục dữ liệu được giữ nguyên.

Nếu bộ cài không tìm thấy MicroStation (cài ở thư mục khác), mở file KTool.cfg trong thư mục cài và chép các dòng trong đó vào file cấu hình người dùng (.ucf) hoặc vào ...\MicroStation\config\appl\.

2.2 Cài tay (khi bước tự động báo lỗi)

  1. Trong MicroStation: Utilities > Macro > Project Manager → Load: nếu đã có C:\KTool\KTool.mvba thì nạp file đó; nếu chưa có thì New → tạo C:\KTool\KTool.mvba (tên project phải là KTool).
  2. Visual Basic Editor (Alt+F11) → File > Import File… → chọn C:\KTool\src\modCaiDat.bas.
  3. Đặt con trỏ trong modCaiDat, chạy macro CaiDat (F5). Macro sẽ nạp các module còn lại, tạo form và mở công cụ.
  4. Có thể chạy lại CaiDat nhiều lần (ví dụ khi cập nhật mã nguồn mới vào src): module đã có sẽ được thay code, không bị nhân đôi. Form giao diện không bắt buộc tên frmMain.

Gắn nút/phím tắt: Workspace > Customize → tạo Tool Box mới, mỗi công cụ đặt key-in tương ứng (xem mục 8), hoặc gán phím chức năng (Workspace > Function Keys).

2.3 Nâng cấp từ phiên bản trước

Công cụ mang tên KTool: project KTool.mvba, key-in vba run [KTool]..., thư mục cài mặc định C:\KTool, file cấu hình KTool_CauHinh.ini.

  • Bộ cài tự gỡ phiên bản trước (nếu có) và xóa file tự nạp cũ trong MicroStation\config\appl, để MicroStation không nạp cùng lúc 2 thanh công cụ.
  • File cấu hình: thư mục DGN còn file cấu hình của phiên bản trước thì lần chạy đầu KTool tự chép sang KTool_CauHinh.ini, giữ nguyên mọi thiết lập.
  • Vị trí, hướng thanh công cụ và file mẫu trường cũ được giữ theo thiết lập trước đó.
  • Dữ liệu trong file DGN (tag thuộc tính thửa, level) không đổi, các tờ bản đồ đã làm trước đây dùng tiếp bình thường.
  • Key-in dùng [KTool] (mục 8).

2.4 Lỗi VBA khi cài sang máy khác: "failed creating the comp manager - 0x80040583"

Thông báo trên thanh trạng thái MicroStation:

VBA interface error: failed creating the comp manager - 0x80040583

(hoặc ... 0x80040502, failed creating the application object - 0x80040562) nghĩa là VBA của MicroStation trên máy đó không chạy được, nên mọi macro VBA (kể cả KTool) đều không nạp được. Đây không phải lỗi của KTool. Nguyên nhân thường gặp:

Nguyên nhân Cách sửa
MicroStation cài không kèm bộ Prerequisite (thiếu Microsoft VBA core / gói ngôn ngữ VBA) – hay gặp với bộ cài rút gọn, bản chép thư mục Cài Prerequisites for Bentley Desktop Applications đúng phiên bản (có trong bộ cài MicroStation hoặc tải từ Bentley), hoặc chạy Repair bộ cài MicroStation
Windows tiếng Việt / ngôn ngữ khác tiếng Anh: VBA chỉ có gói ngôn ngữ 1033 (tiếng Anh), thiếu thư mục ngôn ngữ của Windows (1066…) Sửa lỗi VBA MicroStation tự tạo thư mục ngôn ngữ còn thiếu (chép từ 1033)
Cài Microsoft Office (32 / 64-bit) sau MicroStation, Windows Update làm hỏng đăng ký COM của VBA Sửa lỗi VBA MicroStation đăng ký lại VBE6.DLL / VBE7.DLL và APC*.DLL; nếu chưa được thì Repair MicroStation

Các bước: 1. Đóng MicroStation, chạy Start Menu > KTool > Sửa lỗi VBA MicroStation (SuaLoiVBA.exe, cần quyền Administrator). Công cụ: - tìm các bản MicroStation trên máy và loại VBA tương ứng (V8i: VBA 6.5 32-bit trong Common Files (x86)\microsoft shared\VBA\VBA6; CONNECT: VBA 7.1 64-bit trong Common Files\microsoft shared\VBA\VBA7.1); - tạo thư mục ngôn ngữ VBA còn thiếu, đăng ký lại các thành phần COM của VBA; - nếu chưa cài VBA: báo rõ và cho chọn file cài *.msi của VBA (ví dụ trong thư mục Prerequisites của bộ cài MicroStation) để cài ngay – gói ngôn ngữ *1033*.msi cùng thư mục được cài kèm. 2. Mở lại MicroStation, thử key-in vba run hoặc mở Utilities > Macro > Project Manager: không còn báo lỗi là VBA đã chạy. 3. Chạy Start Menu > KTool > Cài vào MicroStation để nạp KTool.

Bộ cài KTool cũng chạy bước kiểm tra / sửa này tự động lúc cài. Bộ cài không kèm Microsoft VBA vì đây là thành phần Bentley phân phối trong bộ Prerequisite của MicroStation.

Tương thích phiên bản: mã KTool dùng khai báo #If VBA7 … PtrSafe … #Else … #End If, chạy được trên VBA 6.5 32-bit (V8i SELECTseries 1–10, V8 XM) và VBA 7.1 64-bit (CONNECT Edition). Bản V8 2004 trở về trước chưa được kiểm tra.

3. Chuẩn bị trước khi chạy

  • File DGN dùng hệ tọa độ VN-2000, đơn vị chính (master unit) là mét.
  • Từ bản 1.23.0 cấu hình chung lưu ở %LOCALAPPDATA%\KTool\KTool_CauHinh.ini – KTool không tự tạo file cấu hình cạnh file DGN. Thư mục dữ liệu nào đã có sẵn KTool_CauHinh.ini (từ bản cũ hoặc tự chép vào) thì vẫn dùng cấu hình riêng đó. Mở bằng nút Mở file cấu hình… và kiểm tra:
  • [Chung] TyLe, DungSai (mặc định 0,05 m), DoanThuaToiDa, DienTichToiThieu.
  • [Lop]: lớp ranh thửa (mặc định 10), lớp chữ có sẵn (13), lớp vẽ nhãn, lớp vùng thửa (VUNG_THUA), lớp quy chủ, lớp lỗi. Có thể nhập tên level hoặc số level; nhiều lớp cách nhau dấu phẩy. Kiểm tra lại theo bảng phân lớp/quy định kỹ thuật bạn đang áp dụng – giá trị mặc định chỉ là gợi ý.
  • [ThuocTinh] MaLoaiDat: danh mục mã loại đất mặc định lấy theo Phụ lục II Thông tư 08/2024/TT-BTNMT; bổ sung mã cũ (vd. BHK, NHK) nếu dữ liệu còn dùng.
  • File cấu hình đọc theo UTF-8, nên mẫu nhãn có thể có tiếng Việt (ví dụ MauNhan=Chủ: {TENCHU}).
  • Nên đặt tên file DGN có số tờ ở cuối (vd. XuanDai_To15.dgn) để công cụ tự lấy số tờ; hoặc nhập số tờ trên form.
  • Bảng chọn không khóa màn hình (từ bản 1.15.1): khi bảng chọn của một lệnh đang mở, MicroStation vẫn dùng bình thường – lăn chuột phóng / thu, dời hình, chọn đối tượng, Element Information, đo khoảng cách, bật / tắt level, dùng mọi công cụ MicroStation; đọc thuộc tính thửa bằng Bảng thông tin thuộc tính (cũng không khóa). Xong thì bấm Thực hiện để chạy lệnh (lệnh dùng các đối tượng đang chọn ở thời điểm bấm), hoặc Hủy / nút X để bỏ. Nút Làm mới đếm lại đối tượng theo level sau khi vừa vẽ / sửa. Bấm một lệnh KTool khác thì bảng đang mở tự đóng. Đổi sang file DGN khác trong lúc bảng mở thì lệnh không chạy (chạy lại trên file mới). Trong lúc lệnh đang chạy MicroStation vẫn bận như trước. Muốn quay lại kiểu cũ (bảng khóa màn hình): [Chung] BangChonKhongKhoa=0.
  • Kéo co giãn và lăn chuột (từ bản 1.16): kéo cạnh / góc khung các bảng chọn, bảng thuộc tính, bảng sửa lỗi để phóng to hoặc thu nhỏ; bảng chọn kéo dài thì hiện thêm nhiều mục, thu ngắn thì vùng nội dung có thanh cuộn, hàng nút luôn ở dưới cùng. Lăn chuột khi con trỏ nằm trên một ô chọn level: đổi level lên / xuống trong danh sách (ô đang có nhiều level 10,23 thì không ghi đè); con trỏ ở chỗ khác trong bảng: cuộn nội dung bảng; trên danh sách: cuộn danh sách. Tắt: [Chung] LanChuot=0.
  • Level kết quả (từ bản 1.11.1, áp dụng cho mọi chức năng có vẽ / chuyển đối tượng): ô chọn level kết quả có 4 cách:
  • giữ level mặc định của chức năng (vd. TIM_DUONG, CHIEU_DAI_CANH, LOI_TOPO): chưa có thì tạo level mới như trước – trong danh sách ghi mặc định - tạo level mới khi chạy;
  • để trống: đặt kết quả lên level đang hoạt động, không tạo level mới (các ô level dữ liệu như vùng thửa, tâm thửa, nhãn thửa, tim đường thì lấy tên level đang hoạt động lúc bấm OK). Kết quả trên level đang hoạt động không bị tự xóa khi vẽ lại;
  • chọn 1 trong 63 level mặc định của MicroStation (1–63): level chưa có trong file thì tạo đúng số level đó (kiểu tên n hoặc Level n theo file);
  • chọn level có sẵn bất kỳ, hoặc gõ tên mới.
  • Ký hiệu cell TT26: thêm mục Level đặt ký hiệu (theo TT26 từng ký hiệu hoặc 1 level tự chọn / để trống).
  • Mỗi lệnh có sửa dữ liệu sẽ tự lưu và sao lưu file DGN (kèm .ktb) vào %LOCALAPPDATA%\KTool\SaoLuu\<tên file> – không tạo thư mục _SaoLuu cạnh bản đồ (từ 1.23.0); giữ 10 bản mới nhất mỗi file ([Chung] SoBanSaoLuu=10), tắt bằng SaoLuuTruocKhiChay=0. Khi cần quay lại: Undo của MicroStation hoặc mở bản sao lưu.

5.0 Bảng chọn level và tùy chọn

Trước mỗi lệnh, công cụ hiện bảng chọn bố cục gọn kiểu gCadas, gần như không cần cuộn: - Ở trên cùng là ô ghi chú (chữ nhỏ, có thanh cuộn nếu dài). - Các mục được chia thành khung có tiêu đề, thường là Level dữ liệu, Thông số, Tùy chọn; một số lệnh có nhóm riêng (ví dụ Vẽ nhãn thửa: Lớp dữ liệu, Kiểu nhãn và màu chữ, Thu nhỏ và xoay nhãn). Mỗi khung xếp 2 cột "tên mục | ô nhập". - Lệnh có nhiều mục hoặc có bảng gán trường được tách thành các thẻ (tab), ví dụ Tùy chọn chung và Gán trường thông tin. - Level nguồn nhiều level: là một ô nhập (gõ 10, 13 hoặc tên level). Nút … mở hộp tích chọn level, có các nút Chọn level có dữ liệu, Bỏ chọn hết, Hiện tất cả level. - Level đích: chọn trong danh sách (tên, số level, số đối tượng) hoặc gõ tên level mới (tự tạo). - Ô màu: có ô màu xem trước theo bảng màu của file, gõ số màu 0–255 (hoặc 3,4,10-12). Từ bản 1.10: - bấm nút RGB (hoặc bấm vào ô màu xem trước) để mở hộp màu Windows có sẵn các ô Red, Green, Blue: chọn hoặc gõ thông số màu, công cụ tự lấy số màu gần nhất trong bảng màu của file DGN; - có thể gõ thẳng RGB(255,170,50) hoặc #FFAA32 vào ô màu (cả trong danh sách nhiều màu), khi bấm Thực hiện sẽ tự đổi sang số màu; - rê chuột lên ô màu xem trước để xem thông số RGB của số màu đang chọn. - Rê chuột lên ô nhập để xem đầy đủ tên mục. - Kinh tuyến trục: ô chọn tỉnh, bấm mũi tên rồi chọn dòng của tỉnh (khu vực tỉnh cũ), kinh tuyến trục tự điền; vẫn gõ được số độ (107.75, 107°45'). Nút Theo ĐVHC... mở hộp thoại đơn vị hành chính (mục 5.19). - Dòng nút dưới cùng: - Lưu làm mặc định: ghi lựa chọn vào KTool_CauHinh.ini; - Chỉ level có dữ liệu / Hiện tất cả level: lọc danh sách level; - Thực hiện để chạy, Hủy để bỏ. - Tắt bảng chọn bằng [Chung] HienBangChonLop=0.

  • Đường màu xanh lá (thủy hệ, RGB 0,255,0) được giữ nguyên level (tắt được).
  • Áp màu theo Phụ lục 22 mục I.3 cho các đối tượng dạng đường: RGB 255,255,255 cho ranh thửa hiện trạng (10), nhà (14), giao thông (20–25, 27), đê (37–38), địa giới (40, 42, 44, 46), khung (63), điểm khống chế (6–8); RGB 0,255,0 cho thủy hệ (30–34, 36); RGB 255,117,0 cho bình độ (1); RGB 255,0,0 cho ranh theo giấy tờ (61) và quy hoạch (50). Công cụ tự tìm chỉ số màu gần nhất với RGB trong bảng màu của file; chữ ghi chú giữ nguyên màu.
  • Cuối bước, công cụ liệt kê các level còn dữ liệu nhưng không có trong Phụ lục 21 (trừ các lớp làm việc của công cụ) để chuyển lớp tiếp bằng ChuyenLop.
  • Cell nhãn không tự chuyển (báo số lượng): hãy Drop cell trước nếu cần chuyển từng dòng chữ.
  • Chữ không nhận biết được (tên địa danh, ghi chú…) giữ nguyên.
  • Sau đó vẫn áp dụng ChuyenLop, KyHieuTheoLop trong file cấu hình và xóa đối tượng rỗng, chữ trùng, đường trùng.
  • Các đối tượng khác (giao thông, thủy hệ, địa giới…) chuyển bằng ChuyenLop theo bảng Phụ lục 21 ở Phụ lục A cuối tài liệu (cũng có trong file TT26_PhuLuc21_PhanLop.csv).

5.2 Kiểm tra lỗi topo

Chỉ đánh dấu, không sửa. Ký hiệu trên lớp lỗi: - TR cạnh trùng; C cạnh ngắn dưới ngưỡng (mặc định 0,05 m); - H ranh hở sẽ được tự bắt điểm vào cạnh đối diện; HO hở lớn phải nối thủ công; T đường treo / đường dư; - NHO thửa nhỏ dưới ngưỡng (mặc định 1 m²) – được khoanh viền đỏ kèm diện tích; - KT (tùy chọn) thửa từ ngưỡng thửa nhỏ đến ngưỡng kiểm tra để rà soát thêm.

5.3 Sửa lỗi topo

Phá Arc trước khi sửa (mặc định bật, tùy chọn PhaArc): trước khi cắt giao / bắt điểm, các cung tròn, cung elip, đường tròn kín và đường phức (complex string / shape) có chứa cung trên level ranh thửa được chuyển thành đường gấp khúc ngay trên bản vẽ, giữ nguyên level, màu, nét, kiểu nét. Số đỉnh tự tính theo độ lệch dây cung DoChinhArc (mặc định 0,01 m – dây cung không lệch khỏi cung quá 1 cm, góc mỗi đoạn tối đa 10°). Đường cong B-spline và elip kín bị xoay không phá tự động – được báo số lượng để Drop thủ công. Lệnh riêng: menu Chuẩn hóa > Phá Arc thành line.

  1. Cắt tại mọi điểm giao, xóa cạnh trùng (kể cả đoạn chồng lấn một phần), bắt điểm trong dung sai.
  2. Sửa cạnh ngắn: các đỉnh cách nhau dưới ngưỡng được gộp làm một.
  3. Xóa đoạn thừa (overshoot) ngắn hơn ngưỡng.
  4. Bắt điểm ranh hở vào cạnh đối diện gần nhất: ưu tiên kéo dài đường bị hở theo đúng hướng của nó tới cạnh đối diện; nếu không có thì nối tới cạnh gần nhất phía trước. Chỉ tự nối khi khe hở nhỏ hơn KhoangBatHoToiDa (mặc định 1 m). Vị trí đã nối đánh dấu H.
  5. Hở quá lớn (có cạnh phía trước nhưng xa hơn mức tự nối, đến KhoangBaoHoLon – mặc định 10 m): không tự nối, đánh dấu HO để nối thủ công.
  6. Tùy chọn xóa mọi đường dư còn treo (không xóa chỗ hở lớn).
  7. Thửa nhỏ dưới 1 m²: mặc định khoanh viền + đánh dấu NHO để sửa thủ công; tích Tự gộp thửa nhỏ nếu muốn gộp tự động vào thửa bên cạnh (đánh dấu G).
  8. Ghi lại toàn bộ đường ranh (giữ level/màu/nét của đối tượng gốc).

5.4 Tạo topology – vùng thửa và CSDL thửa (.ktb)

Từ bản 1.12, bước tạo vùng không sinh level / shape vùng thửa nữa mà khởi tạo cơ sở dữ liệu thửa đất <tên file DGN>.ktb đặt cạnh file DGN (vai trò như file .gtb khi gCadas khởi tạo CSDL): - Chọn các level khép vùng thửa (ranh thửa, có thể nhiều level: ranh thửa, mép đường, sông suối…) và level tâm thửa (ví dụ level 11). Mục Lưu thửa vào: CSDL thửa .ktb (mặc định) hoặc shape + tag trên level vùng (cách cũ). - Công cụ dò vùng, tính diện tích (trừ thửa nằm lọt bên trong) và ghi mỗi thửa một bản ghi vào .ktb: mã thửa (ID), điểm nhãn, diện tích, toàn bộ trường thuộc tính, tọa độ đỉnh. Không còn giới hạn 5000 đỉnh như shape. - Tạo lại (sau khi sửa ranh): thửa mới nhận lại thuộc tính và mã thửa (ID) của thửa cũ theo vị trí điểm nhãn; hai thửa cũ rơi vào một thửa mới được đánh dấu GOP. - Bản vẽ cũ đã có vùng thửa (shape + tag trên level vùng): lần tạo vùng đầu tiên tự chuyển thuộc tính sang .ktb, tùy chọn xóa các shape cũ (mặc định xóa). Hoặc dùng Thửa đất > Chuyển vùng thửa trên level vào CSDL .ktb để chuyển ngay, không dựng lại topology.

CSDL thửa .ktb (UTF-8, phân cách TAB – mở được bằng Notepad, Excel):

Mục Nội dung
[THONGTIN] file DGN, model, số tờ, tỷ lệ, hệ tọa độ, kinh tuyến trục, ngày khởi tạo, lần cập nhật, số thửa
[TRUONG] danh sách trường thuộc tính (mã + tên hiển thị)
[THUA] ID, XTAM, YTAM (điểm nhãn), DT (diện tích), các trường, SODINH, TOADO (x y;x y;…)
[NHATKY] toàn bộ quá trình thực hiện: mỗi lệnh đã chạy trên tờ (thời gian, lệnh, thời lượng, kết quả, tham số đã chọn)

Liên kết với các bước sau: mọi công cụ dùng thửa – gán thông tin từ nhãn, đánh số, bảng thuộc tính, sửa nhanh, kiểm tra thuộc tính, vẽ nhãn / quy chủ, sơ đồ – hồ sơ thửa, xuất / nhập CSV, Shapefile, KML, MapInfo, tô màu loại đất, đường bao, cạnh thửa, thống kê, chuẩn giao thông – thủy văn, xuất thuộc tính gCadas / FAMIS – đều đọc và ghi trực tiếp file .ktb. Chọn 1 đối tượng bất kỳ nằm trong thửa (nhãn, tâm thửa) để xem / sửa thuộc tính thửa đó. - Sao lưu: mỗi lần sao lưu DGN (%LOCALAPPDATA%\KTool\SaoLuu) đều chép kèm .ktb cùng mốc thời gian. - Chuyển seed, lưu V7: chép kèm .ktb sang file mới. Chuyển kinh tuyến trục: tọa độ đỉnh và điểm nhãn trong .ktb được đổi cùng bản vẽ. Gộp nhiều DGN: các .ktb được gộp thành .ktb của file tổng (số tờ giữ theo từng tờ). Phân mảnh – tách file: mỗi mảnh nhận .ktb gồm thửa có điểm nhãn trong mảnh. Nhập Shapefile: polygon được thêm vào .ktb kèm thuộc tính DBF. - Thửa đất > Thông tin CSDL thửa (.ktb): số thửa, số trường, ngày khởi tạo / cập nhật, số lệnh trong nhật ký; mở file bằng Notepad. - Thửa đất > Vẽ vùng thửa từ CSDL .ktb ra level: vẽ hình thửa thành shape trên level tự chọn (mặc định KTB_VUNG, để trống = level đang hoạt động) để xem, in hoặc chuyển sang phần mềm khác; thuộc tính vẫn ở .ktb. - Nạp thuộc tính từ file .ktt / .ktb khác: gán thuộc tính từ CSDL của bản DGN khác theo vị trí thửa. - Cấu hình [ThuocTinh] LuuTru: TUDONG (mặc định: có .ktb thì dùng .ktb; bản vẽ cũ chưa có .ktb mà có shape vùng thì đọc shape + tag), KTB, VUNG. - Lưu ý: giữ file .ktb đi cùng file .dgn khi chép, gửi dữ liệu. Không sửa cột ID, TOADO bằng tay. - Tâm thửa: đối tượng có sẵn trên level tâm (điểm, chữ hoặc cell) nằm trong thửa được dùng làm điểm đặt nhãn; thửa chưa có tâm sẽ được tạo điểm tâm (lực nét TamThua_Net). Tùy chọn Xóa toàn bộ tâm cũ và tạo lại.

5.5 Thuộc tính thửa

Màu nhãn khi gán thông tin: ô Màu trong bảng gán cho phép chọn màu có trên bản vẽ hoặc gõ tự do bất kỳ số màu 0–255, nhiều màu cách nhau dấu phẩy, dải màu dùng gạch nối (ví dụ 3, 3,4,7, 10-12). Để trống = lấy nhãn mọi màu. Không có màu mặc định áp sẵn.

Lưu trong CSDL thửa .ktb (mục 5.4); bản vẽ dùng cách cũ thì lưu bằng Tag (tag set THUADAT) gắn ẩn trên mỗi vùng thửa. DIENTICH, XNHAN, YNHAN do công cụ tự tính.

Gán thông tin từ nhãn – bảng gán từng trường:

Cột Ý nghĩa
Trường thông tin Số thửa, Mã loại đất, Diện tích pháp lý, Tên chủ, Địa chỉ… và các trường bổ sung
Level chứa nhãn Level có chữ / text node / cell chứa thông tin; để trống = không gán
Màu chữ Màu của dòng chữ cần lấy (danh sách màu có trong bản vẽ, kèm số dòng chữ); để trống = mọi màu. Dùng khi cùng một level có nhiều loại nhãn khác màu, ví dụ loại đất xanh lá, số thửa xanh dương, diện tích đỏ
Cách lấy giá trị Số nguyên (số thửa) · Mã loại đất (kể cả ONT+CLN) · Số thập phân (diện tích) · Toàn bộ nội dung chữ (tên chủ, địa chỉ; nhiều dòng ghép từ trên xuống) · Tên cell · Giá trị tag cùng tên trường

Công cụ tách từng dòng chữ của nhãn (kể cả chữ trong text node và cell lồng nhau) và chỉ lấy dòng chữ có đúng level và màu đã chọn cho trường đó. Với cell, công cụ đọc toàn bộ chữ bên trong cell (kể cả cell lồng nhau), tên cell và tag gắn trên cell. Nhãn nằm trong thửa nào thì gán cho thửa đó. Nhãn mâu thuẫn được đánh dấu TÊN_TRƯỜNG?.

Gán lại: mặc định ghi đè giá trị cũ bằng giá trị mới, nên kết quả tự cập nhật mỗi lần gán. Tích Xóa dữ liệu cũ của các trường được gán trước khi gán lại để làm trống các trường đó ở mọi thửa rồi gán mới (thửa không còn nhãn sẽ để trống). Chỉ các trường có chọn level mới bị xóa; các trường khác giữ nguyên.

Đánh số thửa tự động: theo dải ngang từ trên xuống, trái sang phải (KieuDanhSo=Z hoặc RAN).

Bảng thông tin thuộc tính: hiện toàn bộ thửa dạng bảng (sắp theo số thửa): - ô Tìm (không phân biệt dấu) và bộ lọc nhanh: thiếu số thửa, thiếu loại đất, trùng số thửa, sai mã loại đất, thiếu tên chủ; - chọn một dòng → công cụ phóng tới và chọn thửa trên bản vẽ, các trường hiện ở khung dưới để sửa → Ghi thuộc tính; - bảng là cửa sổ không khóa, vẫn thao tác được trên MicroStation; Nạp lại sau khi chạy lệnh khác.

Mẫu trường thông tin (Excel) – bổ sung trường mới: 1. Bấm Mẫu trường thông tin → Yes: công cụ tạo KTool_MauTruong.csv (cột MA_TRUONG, TEN_HIEN_THI, GHI_CHU) và mở bằng Excel. 2. Thêm dòng cho trường mới, ví dụ SO_GCN | Số giấy chứng nhận, SODINHDANH | Số định danh thửa; lưu dạng CSV UTF-8 hoặc .xlsx. 3. Bấm lại → No → chọn file vừa sửa. Trường mới xuất hiện trong bảng gán từ nhãn, bảng thuộc tính, nhập/xuất dữ liệu. Cũng có thể nạp một file Excel dữ liệu bất kỳ: dòng đầu là tên cột → mỗi cột chưa có sẽ thành một trường mới.

Nhập TT từ CSV / Excel: dòng đầu là tên trường (mã hoặc tên hiển thị, có dấu cũng được). Ghép theo TruongKhoa (mặc định số thửa). Cột chưa có trong danh sách trường → công cụ hỏi có thêm thành trường mới không. Đọc .xlsx cần máy có Microsoft Excel.

  • Đối tượng vẽ: Text Node nhiều dòng (1 đối tượng / thửa – chọn, di chuyển, sửa cả nhãn một lần; MicroStation hiện là Text Node) hoặc Chữ rời từng dòng (cùng graphic group).
  • Tùy chọn: căn giữa / căn trái, ghi kèm tên trường (Tờ: 4, Thửa: 396…), bỏ dòng trường rỗng, cỡ chữ (mm trên giấy), giãn dòng, màu chữ (chọn theo RGB), tự thu nhỏ cho vừa thửa (không nhỏ hơn cỡ tối thiểu), xóa nhãn cũ trên lớp quy chủ (không xóa khi để trống = level đang hoạt động).
  • Kiểu sắp xếp: Theo mẫu nhãn giữ cách cũ: mẫu MauNhan (vd. {SOTHUA} - {LOAIDAT}|{TENCHU}|{DIACHI}), cỡ chữ từng dòng CoChu.
  • Trường Xứ đồng (XUDONG) có sẵn trong cấu hình mới; file cấu hình cũ thì thêm XUDONG vào [ThuocTinh] TruongDuLieu (hoặc Mẫu trường thuộc tính) rồi gán giá trị như các trường khác.

Trường trống (từ 1.18.2): trường không có giá trị nằm giữa nhãn (vd thửa chưa có số thửa giữa số tờ và loại đất) được giữ 1 dòng trống trong Text Node – Edit Text vẫn đủ dòng để gõ bổ sung – hoặc ghi dấu ? / bỏ dòng (tùy chọn Trường không có giá trị). Ký tự rác (NUL, ký tự điều khiển) trong dữ liệu thuộc tính được làm sạch trước khi vẽ.

5.9 Tạo khung bản đồ theo TT 26/2024 (nút Tạo khung bản đồ TT26)

Vẽ theo Điều 4, Điều 5, Phụ lục 02 và mẫu khung Phụ lục 22 (mục III.1), toàn bộ trên level khung (mặc định 63):

  • Khung trong 50×50 cm (1:200 – 1:2.000) hoặc 60×60 cm (1:5.000, 1:10.000); khung ngoài cách 1 cm, nét đậm.
  • Lưới km cách 10 cm trên giấy (chẵn 10 m ở 1:200, 1:500; chẵn 100 m ở tỷ lệ còn lại): vạch ở khoảng giữa hai khung kèm số, dấu chữ thập bên trong khung.
  • Tọa độ góc khung: số km nhỏ và số mét lớn (ví dụ 2337 / 500).
  • Tên BẢN ĐỒ ĐỊA CHÍNH XÃ …, dòng phiên hiệu + TỜ SỐ, tên tỉnh ở góc trên trái, bảng chắp 3×3 (ô giữa gạch chéo), TỜ SỐ dọc bên phải.
  • Phía dưới: TỶ LỆ 1:…, "1 cm trên bản đồ bằng … m trên thực địa", thước tỷ lệ, 4 khối ký (Đo vẽ – Kiểm tra – Xác nhận UBND xã – Duyệt), Tổng số thửa khi thành lập, bảng Ghi chú các thửa đất nhỏ, Bảng các thửa đất chỉnh lý.

Xác định mảnh: để trống Phiên hiệu thì công cụ lấy tâm dữ liệu trên các level đã chọn và tính mảnh chứa nó (gốc X = 0, Y = 500 km; 1:10.000 ô 6 km, 1:5.000 ô 3 km, 1:2.000 đánh 1–9, 1:1.000 đánh a–d, 1:500 đánh (1)–(16), 1:200 đánh 1–100). Nhập phiên hiệu như 725 500-6-d để vẽ đúng mảnh đó. Sau khi vẽ, công cụ báo nếu dữ liệu tràn ra ngoài khung để mở rộng 10 hoặc 20 cm (khoản 3 Điều 4) theo từng phía.

Tên xã, tên tỉnh, cơ quan duyệt: bấm Chọn ĐVHC / KTT... trong bảng chọn để chọn tỉnh – (huyện) – xã; các ô Đơn vị hành chính cấp xã, Dòng tên tỉnh, Cơ quan duyệt được điền sẵn (sửa tay được). Xem mục 5.19.

Bảng chắp: nhập số tờ 8 mảnh liền kề theo thứ tự Tây Bắc, Bắc, Đông Bắc, Tây, Đông, Tây Nam, Nam, Đông Nam. Bảng thửa nhỏ: đặt ThuaNhoDuoi (m²) để tự liệt kê số thửa – diện tích – loại đất của các thửa nhỏ (lấy từ vùng thửa).

5.10 Nhập số liệu đo và nối điểm

Nhập số liệu đo: chọn file .csv / .txt / .dat / .xlsx (bấm nút ...). Cột phân cách bằng phẩy, chấm phẩy, tab hoặc khoảng trắng; khai báo thứ tự cột ở DinhDang (mặc định TEN,X,Y,H,MA, dùng BO để bỏ cột). X là tọa độ Bắc, Y là tọa độ Đông (VN-2000); nếu file ghi Y trước X, công cụ tự đổi. Mỗi điểm được vẽ trên level DIEM_DO kèm số hiệu trên level TEN_DIEM, thông tin STT / TEN / H / MA lưu bằng tag DIEMDO trên điểm. Ví dụ file: mau\Mau_SoLieuDo.csv.

Nối điểm thủ công: gõ chuỗi số hiệu, ví dụ 1-2-3-4-1; 5..12-5 (- nối điểm, ; sang đường mới, a..b là dãy số liên tiếp, lặp điểm đầu ở cuối để khép kín). Có thể nhập đường dẫn file .txt mỗi dòng một chuỗi. Để trống ô này thì công cụ nối các điểm đo đang chọn trên bản vẽ theo thứ tự chọn (tùy chọn khép kín).

Nối điểm tự động theo mã: các điểm có cùng mã được nối theo thứ tự đo.

Mã Ý nghĩa
R1, R1, R1, R1* 4 điểm nối thành 1 thửa khép kín (* = khép về điểm đầu và kết thúc)
N2 … N2* Nhà khép kín

LopTheoMa chọn level theo phần đầu mã, ví dụ R:10,N:14,GT:20 (ranh thửa 10, nhà 14, giao thông 20 theo Phụ lục 21).

5.13 Chuyển đổi font chữ

  • Tự nhận theo tên font (mặc định): chữ dùng font .VnXXX được coi là TCVN3, font .VnXXXH là TCVN3 chữ hoa (chuyển thành chữ IN HOA), font VNI-XXX là VNI-Windows; chữ được chuyển sang Unicode và đổi font theo bảng BangFont (ví dụ .VnTime=Times New Roman, .VnArial=Arial), font không có trong bảng → FontUnicode.
  • TCVN3 / VNI → Unicode (mọi chữ): dùng khi font đã bị đổi nhưng chữ vẫn là mã cũ.
  • Unicode → TCVN3 / VNI: chuyển ngược khi cần trả dữ liệu cho phần mềm cũ.
  • Chỉ đổi font: đổi font mọi chữ trên level chọn sang FontUnicode.

Chữ đã là Unicode thật sẽ tự bỏ qua, không bị chuyển hai lần. Có xử lý chữ trong text node và cell. Bảng mã lấy theo bảng chuẩn của bộ gõ Unikey. Font đích phải có trong Windows (MicroStation liệt kê được).

5.15 Vẽ tim đường, lòng đường

Từ bản 1.10 hai lệnh vẽ đồng loạt: - Nguồn đường ranh – ranh đường giao thông ở level bất kỳ, không bắt buộc level 23: - các đối tượng đang chọn (chọn cả nhóm nhiều đoạn đường, bằng fence / chọn nhiều); - mọi đối tượng cùng level với đối tượng đang chọn: chỉ cần chọn 1 đoạn ranh đường, công cụ lấy toàn bộ đối tượng trên level đó (chọn đoạn ở nhiều level thì lấy tất cả các level đó); - tất cả đối tượng trên các level ranh đường: chọn 1 hoặc nhiều level bất kỳ (gợi ý TT26: 23). - Thủy văn liền kề (mặc định bật; level thủy văn mặc định 30, 31, 32, 34 – sửa được): - đối tượng trên level thủy văn không được lấy làm ranh đường, kể cả khi lỡ chọn cùng (không còn vẽ tim cho sông, kênh); - đường chạy ven sông, kênh mà phía bên kia là bờ sông (không vẽ chỉ giới riêng): bờ sông được nhận là mép đối diện, tim nằm giữa ranh đường và bờ sông; - tia dò mép không vượt qua sông: ranh đường bên kia sông không bị ghép nhầm thành một đường; - ranh đường có cả mép đường bên này và bờ sông bên kia: ưu tiên mép đường (vẽ tim đúng giữa lòng đường, không lệch ra phía sông); - bờ sông trùng hoặc gần trùng ranh đường (lệch dưới 0,2 m) coi như cùng một nét. - Nhận mọi dạng đường: line, linestring, shape, complex string, complex shape (có cung), arc. Thửa đường vẽ bằng shape khép kín vẫn tìm được tim. - Tim đường: - tại mỗi điểm lấy mẫu trên một mép, công cụ bắn tia vuông góc tìm mép đối diện song song gần nhất trong khoảng độ rộng nhỏ nhất – lớn nhất, lấy trung điểm; - hai mép của cùng một đường chỉ cho một tim (tự bỏ trùng), các đoạn tim tự nối liền, làm gọn đỉnh theo dung sai; - mép bị chia nhiều đoạn tại các đỉnh thửa vẫn cho tim liền; chỗ đường đổi độ rộng đột ngột thì tim tách đoạn; - kết quả báo số đường tim và độ rộng nhỏ nhất – lớn nhất; tùy chọn ghi chú độ rộng (level 26), xóa tim cũ trước khi vẽ lại. - Lòng đường (level 22, nét đứt theo mục 5b Phụ lục 22): - theo tim: vẽ 2 nét song song cách tim nửa độ rộng; đoạn nào bờ sông / kênh gần hơn nửa độ rộng thì nét lòng đường phía đó được thu hẹp, cách bờ sông một khoảng lùi, không lấn sang thủy văn; - lùi từ mép: tự xác định phía lòng đường (phía có mép đường đối diện, hoặc bờ sông khi đường chạy ven sông) rồi vẽ nét lùi vào trong một khoảng (vỉa hè); shape khép kín thì lùi vào phía trong. - Tùy chọn xóa nét / tim cũ không xóa khi level kết quả để trống (level đang hoạt động) hoặc trùng level nguồn. - Chạy được cho nhiều tờ (mục 5.21, Phạm vi thực hiện): khi chạy nhiều tờ nguồn luôn lấy theo level.

5.16a Tham chiếu vị trí lên ảnh Google (Bản đồ > Tham chiếu vị trí trên Google Maps / Earth)

  • Tham chiếu theo: đối tượng đang chọn / giữa khung nhìn, tọa độ X, Y của 1 điểm (X hướng Bắc, Y hướng Đông, VN-2000), hoặc số tờ, số thửa (tờ trống = tờ đang mở).
  • Xem bằng: Google Maps (ảnh vệ tinh, cắm ghim đúng tọa độ), Google Earth trên trình duyệt, hoặc Google Earth Pro (file KTool_ViTri.kml có ghim và ranh thửa khi xem theo tờ - thửa).
  • Công cụ báo tọa độ WGS-84 (độ thập phân và độ-phút-giây) để đối chiếu. Đổi VN-2000 → WGS-84 bằng 7 tham số (sai số dưới 1 m); ảnh Google có thể lệch thêm vài mét. Cần khai báo đúng kinh tuyến trục.

5.16 Google Earth, ảnh nền

  • Xem trên Google: mở Google Maps (ảnh vệ tinh) trong trình duyệt tại vị trí đối tượng đang chọn hoặc giữa khung nhìn; hoặc xuất KMZ dữ liệu và mở bằng Google Earth Pro để đối chiếu thửa với ảnh.
  • Gắn ảnh nền có tọa độ: chọn ảnh (JPG, PNG, TIF…) và nhập tọa độ góc trên-trái, góc dưới-phải (VN-2000, hoặc vĩ độ / kinh độ WGS84 đọc trên Google Earth Pro); công cụ tạo world file (.jgw/.pgw/.tfw) có cả hệ số xoay theo độ hội tụ kinh tuyến. Sau đó gắn ảnh bằng File > Raster Manager > Attach, bỏ chọn Place Interactively, ảnh tự đặt đúng vị trí.
  • Công cụ không tự tải ảnh từ máy chủ Google vì điều khoản sử dụng của Google không cho phép tải hàng loạt ảnh bản đồ ngoài ứng dụng của họ. Hãy dùng ảnh bạn có quyền sử dụng (ảnh lưu từ Google Earth Pro theo điều khoản của Google, ảnh bay chụp, ảnh trực giao của dự án…).

5.17 KML / KMZ (Google Earth) và MapInfo

Cần chọn kinh tuyến trục VN-2000 của tỉnh (ô chọn tỉnh trong bảng chọn, hoặc Hệ thống > Đơn vị hành chính và kinh tuyến trục; lưu ở mục [HeToaDo], dùng chung cho KML, MapInfo, Shapefile, Google). Phép chuyển VN-2000 ↔ WGS84 dùng 7 tham số theo QĐ 05/2007 / TT 973/2001 (EPSG VN-2000 to WGS 84 (2)), đã đối chiếu với thư viện PROJ sai lệch dưới 0,1 mm.

  • Xuất KML/KMZ: thửa đất (vùng + toàn bộ thuộc tính trong ExtendedData), điểm đo, đường theo level. KMZ là KML nén, mở thẳng bằng Google Earth.
  • Nhập KML/KMZ: vùng, đường, điểm (kể cả MultiGeometry) vẽ lên các level KML_*, tên ghi vào giữa vùng; tùy chọn ghi thuộc tính trùng tên trường thửa thành tag.
  • Xuất MapInfo: ghi MIF/MID kèm hệ tọa độ VN-2000 (datum 9999, 7 tham số). Trong MapInfo: File > Open (kiểu MapInfo Interchange) hoặc Table > Import, rồi Save Copy As để có file .TAB. Mã chữ UTF-8 cho MapInfo 15.2 trở lên, hoặc TCVN3 (font .VnTime) cho MapInfo đời cũ.
  • Nhập MapInfo: từ file .TAB, trong MapInfo dùng Table > Export ra MIF/MID rồi nhập vào công cụ. Hỗ trợ Region (nhiều vòng), Pline (kể cả Multiple), Line, Point, Text; tọa độ kinh vĩ độ tự chuyển sang VN-2000; chữ mã TCVN3 có thể chuyển sang Unicode.

Công cụ không ghi trực tiếp định dạng nhị phân .TAB/.MAP của MapInfo; MIF/MID là định dạng trao đổi chính thức của MapInfo nên chuyển qua lại không mất dữ liệu.

5.20a Nhập Shapefile (Tiện ích > Chuyển đổi > Nhập Shapefile)

  • Đọc .shp + .dbf (+ .cpg): Polygon, PolyLine, Point, MultiPoint (cả dạng Z, M).
  • Polygon → vùng thửa (shape trên level vùng thửa) kèm thuộc tính tag theo tên trường DBF: SOTHUA / SO_THUA / SHTHUA, SOTO / SO_TO / SHBANDO, LOAIDAT / LOAI_DAT / MDSD, DIENTICH / DT, TENCHU / CHUSUDUNG, DIACHI và mọi trường trùng tên trường thông tin; tùy chọn thêm trường DBF chưa có vào mẫu trường. Seed – kinh tuyến trục – V7 (cũng có ở Tiện ích > Chuyển đổi): - Chuyển file DGN sang định dạng V7 (một tờ hoặc nhiều tờ): lưu bản sao V7 vào thư mục V7 cạnh file (file gốc giữ nguyên). V7 chỉ có 63 level và 1 model; MicroStation CONNECT từ Update 17 không còn lưu được V7 (dùng V8i). - Chuyển seed cho file DGN: tạo file mới từ file seed (đơn vị đo, gốc tọa độ, bảng màu, level, kiểu chữ của seed) rồi chép toàn bộ đối tượng (mọi model) sang, giữ nguyên tọa độ; level chưa có trong seed được tạo theo tên. Kết quả báo số đối tượng và số tag thuộc tính đã chép; nếu thiếu tag hãy Xuất CSV thuộc tính ở file cũ rồi Nhập CSV vào file mới. - Chuyển đổi kinh tuyến trục: tính lại tọa độ VN-2000 của toàn bộ đối tượng trong model từ KTT cũ sang KTT mới (qua kinh độ, vĩ độ; cùng múi 3° hoặc 6°). Line, linestring, shape đổi đúng từng đỉnh; chữ, cell, cung, đối tượng phức đổi theo phép đồng dạng tại tâm (sai số dưới 1 mm với đối tượng dài dưới 1 km). Tùy chọn giữ hướng chữ và ký hiệu; tự ghi KTT mới vào cấu hình. Khung, lưới km, tọa độ góc khung cần tạo lại.

5.33 Ảnh bản đồ quét: đọc, nắn, số hóa (menu Bản đồ > Ảnh bản đồ quét - số hóa)

  1. Đọc ảnh bản đồ quét: chọn ảnh TIFF / JPEG / PNG / BMP; công cụ đọc kích thước, độ phân giải (dpi), tính kích thước pixel theo tỷ lệ (vd 300 dpi, 1:1000 → 0,0847 m / pixel), tạo world file (.tfw, .jgw, .pgw) và gắn ảnh vào bản vẽ. Góc trên-trái đặt bằng cách bấm 1 điểm, nhập tọa độ, hoặc giữ world file có sẵn. Nếu ảnh chưa hiện: Raster Manager > File > Attach, bỏ Place Interactively, Geo Priority = Sister File.
  2. Nắn ảnh bản đồ: bấm lần lượt các điểm khống chế trên ảnh (giao điểm lưới km, 4 góc khung, mốc tọa độ) – sau mỗi lần bấm nhập tọa độ thật (gợi ý sẵn giá trị làm tròn theo lưới). Bấm Reset để kết thúc: công cụ bình sai bình phương nhỏ nhất (Affine 6 tham số từ 3 điểm – khử co giãn giấy theo 2 chiều; hoặc Helmert 4 tham số), báo sai số từng điểm, sai số trung phương (m và mm trên bản đồ), cảnh báo điểm vượt hạn sai (mặc định 0,3 mm × tỷ lệ), ghi <ảnh>_DiemKhongChe.csv; đồng ý thì ghi world file mới (ảnh gốc không bị sửa, world file cũ sao lưu .bak). Raster Manager > Reload để thấy ảnh đã nắn. Có thể nắn luôn các đối tượng đã số hóa trước đó theo cùng phép biến đổi.
  3. Số hóa ranh thửa: đặt level ranh thửa (10) hiện hành, mở Place SmartLine / Line / Shape để vẽ theo ảnh (bật snap để các cạnh nối kín); xong chạy Sửa lỗi → Tạo topology.
  4. Số hóa nhãn thửa: bấm vào giữa từng thửa, nhập 125 ODT 240.5 (hoặc 125/240.5 ONT, chỉ 125) – công cụ ghi số thửa (level 13) / diện tích (4) dạng phân số và loại đất (2); số thửa tiếp theo được gợi ý tự tăng. Reset để kết thúc, rồi Gán thông tin từ nhãn → Vẽ nhãn thửa.

Giới hạn: ảnh méo cục bộ (giấy nhăn, co giãn không đều) cần nắn đa thức / từng mảnh bằng phần mềm chuyên dụng (vd Descartes, IRAS/C); vector hóa tự động (ảnh → đường) không làm được chính xác bằng VBA trong MicroStation nên KTool hỗ trợ số hóa bán tự động như trên.

5.34 Gán thông tin từ FAMIS (.pol, .txt) và TMVmap (*.mdb)

  • FAMIS *.pol (nhị phân) đọc trực tiếp: số tờ, số thửa, mã loại đất, diện tích pháp lý, chủ sử dụng, địa chỉ (TCVN3 tự đổi sang Unicode) và điểm nhãn của từng thửa. Mỗi bản ghi được ghép vào thửa trên bản vẽ có điểm nhãn nằm trong thửa (không cần thửa trên bản vẽ có sẵn số thửa).
  • Mã loại đất của FAMIS là số (vd 60, 21, 52; mã ghép 4 chữ số như 1752 = 17 + 52). KTool tự học bảng mã từ loại đất đã có trên bản đồ (thửa đã gán nhãn) và lưu vào [NhapFamis] BangMa; hoặc nhập bảng mã ở ô Bảng mã loại đất FAMIS dạng 60:ODT, 21:ONT. Mã chưa biết được liệt kê trong báo cáo.
  • Bảng đối chiếu toàn bộ bản ghi ghi ra <tên file>_FAMIS.csv (mở bằng Excel) để kiểm tra.
  • File *.txt phải là bảng thửa (cột Tờ, Thửa, Loại đất, Diện tích, Chủ… hoặc tọa độ X, Y); các dòng tiêu đề / mô tả phía trên dòng tên cột được bỏ qua. Báo cáo MRFClean (*.txt của FAMIS) không phải dữ liệu thửa – KTool báo rõ thay vì gán sai.
  • TMVmap *.mdb: tự chọn bảng ThuaDat (bỏ bảng rỗng), nhận cột ToBD (số tờ), TCT (số thửa), LRD (loại đất), DienTich (diện tích pháp lý khi có DienTichThuc), TenChu, DiaChi, TamX/TamY (điểm nhãn); bỏ cột hình học / kỹ thuật; chữ TCVN3 tự đổi Unicode. Máy 64-bit cần Microsoft Access Database Engine (ACE).
  • Ghép theo = Tự động: có tọa độ điểm nhãn thì ghép theo vị trí trước, dòng không rơi vào thửa nào mới ghép theo số thửa (lọc cùng tờ).

5.35 Thửa bao quanh thửa khác (đường, kênh, thửa có "lỗ")

Thửa giao thông / thủy văn bao quanh các thửa bên trong (topology đúng) nay được xử lý đúng ở mọi chỗ: tìm thửa chứa điểm (nhãn bên trong thuộc thửa bên trong, không bị gán nhầm cho đường), diện tích thực = vòng ngoài – các thửa bên trong, điểm đặt nhãn không rơi vào thửa bên trong, tô sáng trong Bảng thông tin vẽ cả vòng trong (thửa nhiều đỉnh > 4000 cũng tô sáng đủ), xuất Shapefile / GML / KML / MapInfo có vòng trong (polygon có lỗ).

Vẽ vùng thửa từ CSDL và Tô màu thửa theo loại đất (tô đặc) (từ 1.18.3): thửa dạng tuyến bao quanh các thửa bên trong được vẽ thành Grouped Hole của MicroStation – phần tử đầu là vùng đặc theo đúng ranh ngoài, các phần tử sau là lỗ khoét đúng ranh các thửa bên trong (các thửa bên trong liền nhau được gộp thành 1 lỗ theo biên ngoài của cụm, cạnh chung bị triệt tiêu). Màu tô / pattern / đo diện tích (Measure Area) không phủ lên thửa bên trong. Thửa trên 5000 đỉnh vẽ thành Complex Shape kín (không còn bị cắt thành nhiều đường hở). Tích Tô đặc vùng khi vẽ từ CSDL để nhìn rõ phần lỗ. Nếu máy không tạo được Grouped Hole (thiếu thư viện MDL stdmdlbltin.dll), KTool vẽ vòng ngoài + các vòng lỗ riêng và báo số lượng.

5.36 Tạo mới tệp DGN theo VN-2000 (menu Bản đồ)

Tạo tệp DGN mới từ file seed (chọn, hoặc seed mặc định của MicroStation): đơn vị làm việc mét / milimét, tạo sẵn 63 level theo Phụ lục 21 TT 26/2024 (tên = số level, mô tả = các đối tượng), ghi file .prj VN-2000 (kinh tuyến trục theo tỉnh đã chọn, múi 3°, k = 0,9999) cạnh tệp và cấu hình KTool của thư mục (kinh tuyến trục, tỷ lệ, phiên hiệu mảnh, ĐVHC). MicroStation CONNECT: gán hệ tọa độ bằng Geographic Coordinate System > From File chọn file .prj.

5.37 Đánh số hiệu mảnh bản đồ (menu Bản đồ)

5.38 Tính diện tích giải tỏa / thu hồi đất (menu Thửa đất)

Tương tự nhóm Tính diện tích giải tỏa của gCadas (bảng 2 thẻ Cấu hình / Tùy chọn):

  • Vùng quy hoạch: shape / đường khép kín trên Lớp vùng QH (mở rộng đường, kênh, mương, công trình…); không có vùng kín thì KTool tự dựng vùng từ các đường trên lớp đó. Chữ trên Lớp nhãn QH nằm trong vùng là tên dự án.
  • Diện tích trong QH của từng thửa = phần giao chính xác giữa thửa và vùng (trừ các thửa nằm bên trong thửa); ngoài QH = diện tích thửa (hoặc pháp lý, tùy chọn) – trong QH.
  • Nhãn diện tích tại trọng tâm phần bị thu hồi / phần còn lại (ngoặc, ký hiệu A/B, gạch chân, nhãn MDSD tùy chọn), trải pattern gạch chéo phần thu hồi (góc, khoảng cách, màu, lực nét), tính riêng thửa thuộc nhiều dự án.
  • Biểu giải tỏa (Excel): STT, tờ, thửa, loại đất, chủ, địa chỉ, DT pháp lý, DT đồ họa, DT trong / ngoài QH, tỷ lệ %, dự án, thu hồi toàn bộ / một phần, tổng và tổng hợp theo loại đất; tùy chọn ghi DTTHUHOI, DTCONLAI vào thuộc tính thửa.

5.39 Chuyển mã loại đất / đối tượng cũ sang mới (TT 08/2024)

Tham chiếu và chuyển mã loại đất, mã đối tượng sử dụng / quản lý đất cũ (TT 27/2018, 28/2014, 25/2014, 08/2007) sang mã theo Luật Đất đai 2024 và Phụ lục II TT 08/2024/TT-BTNMT, cho các trường thuộc tính (LOAIDAT, DOITUONG…) và nhãn chữ trên bản vẽ (mã ghép ONT+CLN đổi từng phần). Có tùy chọn chỉ báo cáo; danh sách chi tiết ghi ra <tên file>_ChuyenMa.csv. Bảng tham chiếu nằm trong QuyDinh.ini mục [ChuyenMa] (sửa được, cập nhật qua mạng); lệnh Bảng tham chiếu mã loại đất cũ - mới xuất bảng ra Excel.

5.41 Xuất CSDL sang gCadas và liên kết dữ liệu hai chiều (.gtp)

File .gtp của gCadas là CSDL SQLite được mã hóa. KTool tự giải mã ngay trên máy (không cần mật khẩu, không cần cài thêm – dùng thư viện SQLite có sẵn của Windows 10 trở lên), đọc / ghi các bảng thửa đất rồi mã hóa lại; chỉ ghi các trang dữ liệu thay đổi.

  • Xuất CSDL bản đồ sang gCadas (.gtp) (menu Thửa đất > Liên kết gCadas, hoặc menu Chuyển đổi): chọn 1 file .gtp mẫu của gCadas cùng xã (lấy danh mục, đơn vị hành chính – có thể tạo bằng Kết nối CSDL của gCadas cho 1 bản vẽ trống). KTool sao file mẫu thành <tên bản vẽ>.gtp, xóa dữ liệu thửa / chủ có sẵn trong mẫu, ghi toàn bộ thửa: số tờ, số thửa, diện tích, diện tích pháp lý, địa chỉ, mã loại đất (bảng DaMucDichSuDung, mã ghép ONT+CLN thành nhiều mục đích), chủ sử dụng và đối tượng (Nguoi, DangKyThua), hình thửa (geom, thửa bao quanh có lỗ), tâm thửa. Mở bản vẽ trong gCadas và Kết nối CSDL tới file này; muốn sửa hình thửa trong gCadas thì chạy Tạo topology của gCadas.
  • Liên kết dữ liệu hai chiều với gCadas: chọn file .gtp (trống = file đã liên kết hoặc <tên bản vẽ>.gtp cạnh bản vẽ) và chiều đồng bộ:
  • KTool -> gCadas: ghép thửa KTool với thửa gCadas theo vị trí (tâm thửa gCadas rơi vào thửa KTool, điểm nhãn KTool nằm trong thửa gCadas), còn lại theo số tờ + số thửa; chỉ ghi trường có thay đổi, giá trị trống trong KTool không xóa dữ liệu gCadas; thửa có trong KTool mà chưa có trong .gtp được thêm (tùy chọn); thửa chỉ có trong gCadas giữ nguyên. Chủ dùng chung cho nhiều thửa thì tách người mới, thửa đồng sử dụng (nhiều chủ) không đổi tên chủ.
  • gCadas -> KTool: đọc .gtp thành bảng (số tờ, số thửa, loại đất, diện tích, diện tích pháp lý, chủ, địa chỉ, đối tượng, ghi chú, điểm trong thửa) rồi gán vào thửa như lệnh Nhập thông tin từ bảng (lệnh này cũng mở trực tiếp được file .gtp).
  • Tự động: bản vẽ đã liên kết thì sau mỗi lệnh / thao tác làm thay đổi thuộc tính thửa (gán nhãn, đánh số, nhập bảng, chuyển mã, sửa trong ô thông tin / bảng thuộc tính…), KTool tự cập nhật vào .gtp và báo trên thanh trạng thái.
  • An toàn: KTool khóa file theo đúng cơ chế của SQLite – gCadas đang đọc / ghi thì KTool chờ, gCadas không đọc dở dữ liệu đang ghi; có giao dịch gCadas chưa hoàn tất (file -journal) thì KTool không ghi. Trước lần ghi đầu tiên trong phiên, file .gtp được sao lưu vào %LOCALAPPDATA%\KTool\SaoLuu\gCadas (giữ 5 bản mới nhất). Giải mã sai (kiểm tra quick_check) thì không ghi. Ghép được quá ít thửa (bản vẽ khác hệ tọa độ / tờ khác) thì không thêm thửa mới. Đang mở dự án trong gCadas: ngắt / kết nối lại CSDL để gCadas nạp dữ liệu mới.
  • Mã loại đất: gCadas lưu mã theo id danh mục kiểm kê; đất ở kết hợp (ODT+CLN, ODT+HNK…) có id riêng và ghi thành 1 mục đích, các tổ hợp khác ghi thành nhiều mục đích. Bảng id có sẵn (LUC, LUK, HNK, CLN, NTS, ONT, ODT, SKX, DGT, DTL, DRA, TON, TIN, NTD, SON, BCS, NCS, ODT+CLN, ODT+HNK) và tự học thêm từ chính file .gtp (cột mã ghép gCadas ghi cho từng thửa) và từ thửa đã ghép. KTool cũng tự theo cách ghi cột mã ghép của phiên bản gCadas tạo file ("ODT+CLN" cho mọi thửa, hay "HNK + LUK" chỉ cho thửa nhiều mục đích). Cùng tập mã (khác thứ tự / khác cách ghi) thì giữ nguyên dữ liệu gCadas. Mã chưa biết được ghi theo danh mục mục đích sử dụng (DM75) hoặc cột mục đích chi tiết và liệt kê trong báo cáo – bổ sung bằng [Gcadas] MaKiemKe=MÃ=id,... trong cấu hình. Mã mới theo TT 08/2024 mà danh mục gCadas chưa có cần chọn lại trong gCadas.
  • Báo cáo chi tiết từng thửa: <tên bản vẽ>_gCadas.csv (cập nhật / thêm mới / chỉ có trong gCadas).

5.42 Gán thông tin từ nhãn – tất cả dạng nhãn trong 1 giao diện

Nút Gán thông tin từ nhãn gộp mọi dạng nhãn vào 1 bảng thiết lập nhiều thẻ, bấm Thực hiện 1 lần là chạy lần lượt và gom kết quả vào 1 thông báo:

  • Thẻ Các bước: tích dạng nhãn có trên bản vẽ – (1) nhãn địa chính: phân số / 3 dòng, 1 dòng (12 LUC 350.5), Số thửa-Diện tích, Số thửa/Diện tích, cell, LUK240-236.5, 284A, nhãn tràn hoặc nằm ngoài thửa nhỏ; (2) nhãn có mũi tên chỉ vào thửa nhỏ; (3) nhãn quy chủ; (4) bảng thửa nhỏ ở góc khung; đánh dấu thửa còn thiếu số thửa / loại đất (THIEU_SO, THIEU_LD).
  • Thẻ Gán trường thông tin: level / màu / cách lấy giá trị cho từng trường. Để trống toàn bộ thì KTool tự nhận dạng nhãn trên mọi level chứa nhãn.
  • Thẻ Nhãn phức tạp – thửa nhỏ, Nhãn quy chủ, Bảng thửa nhỏ: thông số từng dạng.
  • Nhãn quy chủ: mỗi thửa 1 nhãn nhiều dòng (Text Node hoặc chữ rời xếp chồng). Các dòng theo Thứ tự dòng (như khi vẽ nhãn quy chủ), có thể kèm tên trường (Tờ: 4, Thửa: 396); dòng trống / ? là trường chưa có giá trị. KTool kiểm tra kiểu từng dòng (số hiệu, mã loại đất, diện tích, chữ) nên nhãn bỏ dòng trống vẫn gán đúng.
  • Bảng thửa nhỏ góc khung: chỉ cần bấm 1 góc bảng (góc trên hoặc góc dưới) – KTool tự nhận khung bảng (theo kích thước bảng Rộng × Cao mm nếu nhập, không thì gom các ô chữ liền kề theo hướng có bảng) rồi tự tách cột STT / số thửa / loại đất / diện tích.
  • Các lệnh gán riêng từng dạng vẫn giữ trong menu (nhóm Gán riêng từng dạng nhãn).

5.43 Bảng thông tin thuộc tính: tự sắp xếp, ẩn / hiện, lọc lỗi → Sửa nhanh

  • Kéo cửa sổ theo bất kỳ hướng nào: hàng nút tự xuống dòng; khung Thuộc tính thửa đang chọn tự chia số cột theo bề rộng (hẹp → 1 cột chạy dọc, rộng → 2–4 cột), thiếu chỗ thì có thanh cuộn; danh sách thửa luôn giữ ít nhất 1/3 chiều cao.
  • Nút Ẩn thuộc tính / Hiện thuộc tính: ẩn khung để danh sách chiếm toàn bộ cửa sổ (nhớ cho lần sau).
  • Bộ lọc mới: thiếu số thửa, thiếu loại đất, thiếu diện tích pháp lý, thiếu tên chủ, trùng số thửa, sai mã loại đất, mâu thuẫn khi gán (giá trị có dấu ?), lệch DT pháp lý – đồ họa (quá [BangTT] LechDT %, mặc định 5%), thửa thừa (chưa có thông tin), có lỗi bất kỳ.
  • Nút Sửa nhanh ►: chuyển các thửa đang lọc sang menu Sửa nhanh của thanh công cụ (bắt đầu từ dòng đang chọn). Trong menu Sửa nhanh: ◄ Thửa trước / Thửa sau ► (tự phóng tới thửa, tô sáng ranh, nạp thuộc tính), Ghi + sang thửa sau; cũng có thể chọn bộ lọc ngay trong menu và bấm Lập DS mà không cần mở bảng. Trường hiện trong Sửa nhanh đặt ở [SuaNhanh] Truong= (tối đa 10 trường, mặc định Số tờ, Số thửa, Loại đất, DT pháp lý, Tên chủ, Địa chỉ).

5.46 Diện tích từng loại đất (thửa đa mục đích)

Lệnh Diện tích từng loại đất: tự tạo cặp trường LD1 / DTLD1, LD2 / DTLD2… theo số mục đích lớn nhất trong các nhãn đa mục đích (CLN+ONT → 2 cặp, CLN+NTD+HNK → 3 cặp), điền mã từng loại đất.

  • Thửa 1 mục đích: DTLD1 = diện tích pháp lý (trống thì diện tích đồ họa).
  • Thửa nhiều mục đích còn trống diện tích: để trống (nhập tay theo hồ sơ), đất ở theo hạn mức (ONT / ODT = hạn mức, còn lại chia đều), chia đều, hoặc toàn bộ cho loại đầu.
  • Kiểm tra tổng DTLD = diện tích thửa; thửa lệch ghi vào <tên file>_DTLoaiDat_Lech.csv.
  • Tích Tự tạo trường sau lệnh Gán thông tin từ nhãn để số cặp trường tự tăng khi gặp nhãn nhiều mục đích hơn.
  • Khi liên kết gCadas: DTLDi ghi vào diện tích từng dòng mục đích sử dụng của thửa; đọc .gtp thì diện tích từng mục đích về LDi / DTLDi.

5.50 Menu "Thửa đất" – quy trình đánh số thứ tự

Menu Thửa đất (dạng cây, mục Quy trình xử lý thửa đất (1 -> 6)) gom các bước xử lý theo thứ tự thực hiện (Kết nối CSDL chỉ còn ở menu Hệ thống):

  2. Sửa lỗi Topology – 2.1 Sửa lỗi tự động; 2.2 Sửa lỗi thủ công (từng lỗi)
  3. Xóa đánh dấu lỗi (sau khi đã sửa hết lỗi)
  4. Tạo vùng thửa đất + CSDL thửa (*.ktb)

5.51 Nhập CSDL bản đồ gCadas (.gtp) vào CSDL thửa (.ktb)

5.52 Menu "Tiện ích" theo nhóm gCadas

  • Tiện ích cho Text: tìm và thay thế (1 tờ / nhiều file); tìm kiếm, thay thế theo điều kiện (lọc nội dung, màu, font, cỡ chữ → đổi level, màu, font, cỡ chữ, lực nét); đập TextNode ra Text; nhãn tọa độ 3 số thập phân → 2 số; Text → TextNode (từng chữ, hoặc gộp các chữ đang chọn thành 1 node); tách Text thành TextNode theo ký tự phân cách; đổi font TCVN3 / VNI → Unicode...
  • Tiện ích cho Line: màu, lớp line trong nhãn; LineStyle, lực nét; chuyển level theo màu (bảng 3=10;2=31); dịch từ tọa độ giả định sang tọa độ thật (dX, dY); vẽ đầu mút (tất cả / đầu mút treo); nối các line được chọn; vẽ line kèm chiều dài.
